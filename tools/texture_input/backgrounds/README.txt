Put the four host background PNGs here (16x16, opaque):

    stone.png        -> Overworld stone ore background
    deepslate.png    -> Overworld deepslate ore background
    netherrack.png   -> Nether ore background
    endstone.png     -> End ore background

Any you leave out are simply skipped.

The four checked in here are the flat host colours the mod's generated block textures already
use (stone #7f7f7f, deepslate #48484e, netherrack #5e2020, end stone #dbdeab), so a new overlay
composites onto exactly the same backgrounds as its neighbours. Replace them to restyle the lot.
