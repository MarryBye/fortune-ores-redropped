Put one ore-overlay PNG per material here. Each is just the ore bits ("cameshki") on a
FULLY TRANSPARENT background, 16x16. The file name (without .png) is the material name.

Materials used by the world generator:

    coal  diamond  redstone  lapis  emerald  ruby  topaz  sapphire
    iron  gold  malachite  tanzanite  shadow  draconium

Example:  coal.png  ->  ore_coal.png, deepslate_ore_coal.png,
                         netherrack_ore_coal.png, endstone_ore_coal.png
